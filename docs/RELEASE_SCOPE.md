# v0.2 release scope

This is a new offline diagnostic implementation written for this repository. It does not copy HALTSEAL's private payment-execution kernel, private release records, unpublished patent specifications, customer histories, or existing qualification-kit internals.

## Included

- Dependency-free Python runtime and a one-command checkout quickstart.
- A versioned, strict public workflow format with separate structural and chronology/reference validation.
- Sixteen newly authored synthetic trace fixtures and sixteen separately authored local-function challenges.
- Script-free HTML, a compact workflow-owner HTML brief, and structured JSON reports, with source, scope, evidence gaps, exact-action findings, and explicit limits.
- Before/after local decision comparison, explicit advisory/gate modes, and local-versus-workflow follow-up actions.
- Stateless teaching examples, an unbound customer adapter, a customer CI template, meaningful regression tests, packaging, and GitHub CI.
- An optional path to a scoped paid workflow assessment.

## Not established by this release

- Live payment control, provider/bank adapters, evidence authentication, or production execution.
- Complete organizational coverage, correct mapping of real obligations, signature verification, policy-currentness, or distributed concurrency guarantees.
- Partial-payment, refund, FX, split-payment, netting, or financial-ledger behavior.
- A third-party audit, certification, independently reproduced customer protection, adoption count, or production-readiness conclusion.

The replay maintains only enough local diagnostic state to interpret a supplied trace. It is not a deployable authority or payment-admission service. Fixture code must not be connected to a payment execution boundary.

## Distribution scope

The public repository is prepared from reviewed diagnostic source with a fresh initial Git history. The source ZIP contains diagnostic files and applied licensing files. Public CI and release tooling are separately inventoried. The applied license and attribution accompany the reviewed release.

The lab does not transfer commercial control source or patent title. Package verification cannot establish legal ownership, noninfringement or production protection.
